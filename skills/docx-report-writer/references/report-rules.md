# 보고서 작성·디자인 규칙 (R1~R16)

각 규칙 옆의 **[자동]** 은 `build_report.py`가 자동으로 적용하는 것, **[검사]** 는 `check_report.py`가 검사하는 것,
**[작성자]** 는 글을 쓰는 사람(Claude)이 지켜야 하는 것이다.

## A. 문서 구성

| ID | 규칙 | 적용 |
|---|---|---|
| **R1** | 문서는 **표지 → 목차 → 요약 → 본문(서론·본론·결론) → 참고문헌** 순서로 구성한다. 첫 장은 '요약', 마지막 장은 '참고문헌'이다. | [자동][검사] |
| **R2** | **표지**에는 보고서 종류, 제목, 부제, 소속, 작성자, 작성일을 가운데 정렬로 넣는다. 표지는 별도 구역으로 두고 머리글과 쪽 번호를 넣지 않는다. 표지는 한 쪽을 넘지 않는다. | [자동][검사] |
| **R3** | **목차**는 Word 자동 목차(제목 1~2 수준)로 만든다. 항목을 클릭하면 해당 장으로 이동하고, 쪽 번호는 실제 쪽과 같아야 한다. | [자동][검사] |
| **R4** | 장 제목은 `1.`, `2.` 처럼, 절 제목은 `1.1`, `1.2` 처럼 번호를 붙이고 번호는 연속되어야 한다. ('요약', '참고문헌'은 번호 없음) | [자동][검사] |

## B. 서식·디자인

| ID | 규칙 | 적용 |
|---|---|---|
| **R5** | 용지는 **A4**(210×297mm), 여백은 상·하·좌·우 **25mm**이다. | [자동][검사] |
| **R6** | 본문은 **맑은 고딕 11pt, 줄 간격 1.4배, 양쪽 정렬, 문단 뒤 6pt**로 쓴다. | [자동][검사] |
| **R7** | 제목 1은 16pt 굵게, 남색(#1F3864)에 아래 구분선을 둔다. 제목 2는 13pt 굵게, 파랑(#2E75B6)이다. 제목은 다음 문단과 같은 쪽에 둔다. | [자동][검사] |
| **R8** | **머리글**은 오른쪽에 보고서 제목(9pt, 회색)과 아래 구분선을 둔다. **바닥글**은 가운데에 `- 현재 쪽 / 전체 쪽 -` 형식의 쪽 번호를 넣는다. 본문 쪽 번호는 1부터 시작한다. | [자동][검사] |
| **R9** | **표**는 표 위에 `표 n. 제목 [출처]` 캡션을 단다. 머리행은 남색 배경에 흰 굵은 글씨이며 쪽이 바뀌면 반복한다. 데이터 행은 줄무늬로 구분한다. 12행 이하의 표는 쪽 사이에서 나뉘지 않게 한다. 보충 설명은 표 아래 `※`로 단다. | [자동][검사] |
| **R10** | **그림**은 가운데 정렬하고, 그림 아래에 `그림 n. 제목 [출처]` 캡션을 단다. 그림, 캡션, 주석은 같은 쪽에 둔다. 차트는 한글 폰트를 쓰고 값 라벨을 표시한다. 모든 표와 그림은 본문에서 `{tbl:id}`/`{fig:id}`로 한 번 이상 언급한다. | [자동][검사][작성자] |
| **R13** | **핵심 요약**은 연한 파랑 음영과 왼쪽 굵은 선이 있는 강조 박스에 넣는다. | [자동][검사] |

## C. 인용·출처

| ID | 규칙 | 적용 |
|---|---|---|
| **R11** | 본문의 모든 수치·사실 주장 뒤에 `[n]` 인용을 단다. **`[n]`을 클릭하면 참고문헌의 해당 항목으로 이동**한다(내부 링크 + 북마크). | [자동][검사][작성자] |
| **R12** | **참고문헌**은 본문에 처음 인용된 순서로 번호를 매긴다. 형식은 `[n] 저자, "제목," 출처(학술지, 권(호), 쪽), 연도. 링크`이다. **모든 항목에 클릭 가능한 DOI 또는 URL 하이퍼링크**를 넣는다. 인용되지 않은 참고문헌은 두지 않는다. | [자동][검사] |
| **R14** | **사실 정확성**: 출처를 직접 확인한 정보만 쓴다. DOI는 Crossref로, 수치는 초록이나 원문으로 확인한다. 추정이나 의견은 '~로 보인다', '시사점' 등으로 사실과 구분한다. 문체는 '~다' 평서문이다. 전문용어는 처음 나올 때 영문을 함께 쓰고, 약어는 처음 나올 때 풀어 쓴다. | [작성자] |

## D. 파일·검증

| ID | 규칙 | 적용 |
|---|---|---|
| **R15** | 파일명은 `{주제}_보고서_{YYYYMMDD}.docx`로 한다. 문서 속성에 제목, 부제, 작성자, 키워드를 넣는다. | [자동][검사] |
| **R16** | 제출 전에 `check_report.py --links`의 FAIL이 0개여야 한다. PDF 미리보기로 표지 넘침, 목차 쪽 번호, 표·그림 분리, 빈 쪽을 눈으로 확인한다. | [검사][작성자] |

## 디자인 토큰 (build_report.py 상단에서 변경 가능)

| 항목 | 값 |
|---|---|
| 글꼴 | 맑은 고딕 (영문 Malgun Gothic) |
| 본문 | 11pt / 줄 간격 1.4 |
| 주 색상 | 남색 `#1F3864`, 파랑 `#2E75B6`, 링크 `#0563C1` |
| 표 머리행 / 줄무늬 | `#1F3864` / `#F2F5FA` |
| 강조 박스 | 배경 `#EAF1FB`, 왼쪽 선 `#2E75B6` |
| 여백 | 25mm |
